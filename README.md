## Description

This repository contains my solution for Assignment #1 (HTML & CSS Basics).
It's a small multi-page website built with plain HTML and CSS, covering personal
page styling, layout with divs/floats, a tribute page, and a table/form styling
exercise.

## Live demo

https://asikxz008.github.io/Assigment1-webTech1-Aslan/

## Project structure

```
├── index.html          → Task 1: Personal page + profile card
├── styles.css
├── task2.html           → Task 2: Layout with div + float (no flexbox/grid)
├── task2.css
├── exercise1/
│   ├── index.html       → Task 3: Tribute page (Cristiano Ronaldo)
│   └── styles.css
├── task4.html           → Task 4: Table (student grades) + feedback form
├── task4.css
```

## How to run locally

Just open `index.html` in any browser — no build step or dependencies needed.

## Navigation

Every page has a navbar at the top linking to all tasks (Task 1 → Task 4), so you
can move between them without going back to the repo.
