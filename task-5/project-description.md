## Project Description

AutoParts Online Store is an online shopping website designed for selling automotive spare parts and accessories. The website allows users to browse different product categories, view available spare parts, and contact the store for more information.

The target users of this website are car owners, drivers, and automotive specialists who need a convenient way to find vehicle components online. The main purpose of this project is to create a simple and user-friendly platform for searching and purchasing auto parts.

The website includes five main pages: Home, Products, Categories, About Us, and Contact. Each page has a consistent header, navigation menu, and footer design.
